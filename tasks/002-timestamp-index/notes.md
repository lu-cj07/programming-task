2. size_t 与中点溢出：
   若直接进行(begin + end)/2运算，对于长度为n的线性表，最多中间运算会加得到 2n - 1，有可能出现加法溢出，于是采用(end - begin)/2 + begin 则能够保证在线性表长度有效时，不会出现溢出，因为中间运算值一定小于n。
   - 参考来源：
3. 半开区间的优点：
      - 二分查找中区间的含义：
        - 表示目标元素所在的区间，若使用全闭区间([begin,end]):表示目标可能在begin、end指向的位置以及二者之间的位置，所以循环的不变量是begin <= end。
        - 使用半开区间时（[begin,end)），表示tag只会出现在begin指向的位置以及二者之间，所以循环的不变量是begin < end。
